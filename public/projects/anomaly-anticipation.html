01 / Problem

異常そのものより、異常が起きる前のデータが足りない。

異常予兆検知では、事件や事故が起きる直前の映像を大量かつ多様に収集することが難しく、学習データ不足が性能上限になり得ます。そこで生成動画を実映像の代替ではなく、不足する予兆パターンを補う学習データとして扱います。

02 / My Contribution

生成から検知まで、リークを避けた評価設計を構築。

  1. Dataset design
    UCF-CrimeをGen-train / Det-train / Testへ分離し、生成側と評価側の混入を防止。
  2. Video generation
    LTX-Video LoRAを用いて不足する予兆映像を生成。
  3. Mixture experiment
    実映像と生成映像の混合率を段階的に変更して学習。
  4. Detector comparison
    RTFM / UMIL / VadCLIPを用いて複数手法で効果を比較。
  5. Evaluation
    AUC / AP / LaAPを使い、異常検知性能と予兆性能を評価。

03 / Key Decisions

生成品質ではなく、実映像への汎化で価値を判断する。

  • 生成モデル学習用データと検知モデル学習用データを分離する。
  • Testは実映像のみで固定し、生成映像そのものを評価対象に混ぜない。
  • 生成データ量を増やすだけでなく、混合率ごとの性能変化を見る。
  • 生成データが性能を下げる条件も失敗例として分析する。

04 / Evaluation

異常を当てるだけでなく、どれだけ早く気づけるかを評価。
