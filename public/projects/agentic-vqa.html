01 / Overview

長時間映像QAを、観測可能な処理へ分解する。

長時間映像では、すべての映像情報を一度にVLMへ渡すことが難しく、質問ごとに必要な根拠も異なります。本研究では、映像・ASR・OCR・視覚情報を事前処理し、質問に応じて必要なEvidenceを検索してから回答を生成・検証する構成を採用しています。

02 / My Contribution

研究設計から評価Viewerまで、システム全体を実装する。

  1. Architecture
    長時間映像QAのOffline / Online処理と主要モジュールを設計。
  2. Evidence pipeline
    映像・ASR・OCR・視覚情報を保存し、質問に応じてEvidenceを取得する処理を実装。
  3. Generation & verification
    候補回答生成、Reranking、Verificationを分離し、再試行可能な構成を実装。
  4. GPU inference
    Qwen3-VLをvLLM上で実行する推論基盤を構築。
  5. Evaluation
    質問タイプ・Evidence取得・回答生成ごとのFailure AnalysisとViewerを整備。

03 / Key Decisions

精度だけでなく、どこで失敗したかを追えるようにする。

  • Offline処理とOnline処理を分離し、質問時に必要な情報だけを取得する。
  • Retriever / Generator / Rerankerを分け、各段階の失敗を個別に評価できるようにする。
  • 最終精度だけでなく、Evidence選択ミスと回答生成ミスを分離して分析する。
  • 再生成・再計画を追加できる構成にし、改善点を局所化する。

04 / Evaluation

現在は、Evidence取得と回答生成の寄与を切り分けて評価中。

回答精度、根拠整合性、質問タイプ別性能、Failure Analysisを用いて、システムのどの段階が性能上限になっているかを分析しています。確定していない結果は公開せず、再現可能な評価が固まった数値のみ追加します。
