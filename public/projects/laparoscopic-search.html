01 / Problem

100時間を超える手術動画から、必要な数秒へたどり着く。

長時間の手術動画から特定場面を探す作業は大きな負担です。視覚的な類似度だけでは、似た映像が多い手術動画の中で「手術工程のどの段階か」という時間的文脈を十分に扱えません。

02 / My Contribution

データ処理、検索、再順位付け、評価を一つのパイプラインとして設計。

  1. Dataset processing
    75本・104.75時間の動画から5秒間隔で75,441フレームを抽出・索引化。
  2. Semantic retrieval
    Qwen3-VL-Embeddingを用いて自然言語クエリとフレームを同一空間で検索。
  3. Cluster-aware refinement
    初期候補周辺のクラスタを再探索し、関連場面を補完。
  4. Temporal reranking
    手術工程上の時間的位置をランキング信号として追加。
  5. Evaluation
    MRR@10、Hit@1/5/10、nDCG@10、Mean Rank等で比較評価。

03 / Key Decisions

「似ている一枚」から「場面として妥当な位置」へ。

  • 視覚言語埋め込みだけで完結させず、クラスタ構造を再検索に利用する。
  • 手術動画特有の工程順序を追加信号として扱う。
  • 単一指標だけで判断せず、MRR・Hit@K・nDCG・Mean Rankを併用する。
  • 時間重みが効かないクエリも含め、改善と悪化の両方を分析対象にする。

04 / Result

時間情報を用いたランキングでMRR@10を改善。

0.815Temporal ranking
0.755Text-only baseline
+0.060absolute improvement

時間情報は最終ランキングを改善しました。一方で、すべてのクエリで一様に有効ではないため、今後はクエリ適応的な重み付けが課題です。
